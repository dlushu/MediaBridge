# 插件契约

> 本文已移至开发套件仓：[MediaBridge-plugin-devkit](https://github.com/dlushu/MediaBridge-plugin-devkit) 的
> `framework/contracts/plugin-contract.md`（本机：`../MediaBridge-plugin-devkit/framework/contracts/plugin-contract.md`）。

插件能做什么、面板会怎么调它、哪些必须遵守 —— **权威那一份在开发套件仓**，因为契约是插件侧与面板侧共同的约定，
放在哪一边都会让另一边变成副本。这里只留一条指路，免得同一份契约在两个仓库里各自漂移。

面板代码与文档里 `见 docs/plugin-contract.md` 这类引用仍指这一路径（指的就是上面那份）。
