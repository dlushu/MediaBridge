# ADR-0069 品牌图形资产：界面内不摆图标，标签页图标与 Emby 默认头像用品牌图

- 状态：已采纳
- 相关：[branding.js](../../server/core/branding.js)（产品名，图形不在其中） ·
  [public/logo.png](../../public/logo.png)（标签页图标） ·
  [default-avatar.png](../../server/modules/emby/assets/default-avatar.png)（Emby 默认头像） ·
  [0018](0018-branding-single-source.md)（产品名只在一处定义）

## 背景

面板此前**没有任何品牌图形**：界面（顶栏、日志、登录页标题位）只有文字，浏览器标签页没有图标，
Emby 默认头像用的是一张早期占位图。产品名已由 [0018](0018-branding-single-source.md) 收敛到
`branding.js`，但图形资产一直没定。

品牌图形确定后（绿色三角/人字形，播放元素为主形、桥梁为暗喻），需要决定把它落在哪些位置。
`branding.js` 里记着一条既有决策：**界面内不摆图标** —— 顶栏与日志只有文字。

## 决定

**品牌图形只在两处落地，界面内仍不摆图标：**

| 位置 | 资产 | 尺寸 |
|---|---|---|
| 浏览器标签页图标（favicon） | [public/logo.png](../../public/logo.png) | 512×512 透明底 |
| Emby 默认头像 | [default-avatar.png](../../server/modules/emby/assets/default-avatar.png) | 606×606 透明底 |

- **浏览器标签页图标**是浏览器 UI，不属于面板自己的界面布局：`index.html` 与 `login.html`
  各加一条 `<link rel="icon" type="image/png" href="/logo.png" />`。README 顶部也引用这张图。
- **Emby 默认头像**沿用 [0056](0056-emby-compat-scope.md) 的口径，仍是"所有用户共用一张品牌图"；
  本条只**换图**，尺寸与 `tag` 口径（606×606 透明底、`tag` = 文件内容 md5）不变。
- **界面内保持纯文字**：顶栏、启动日志、登录页标题位都不加图标 —— 既有决策继续成立，
  `branding.js` 的注释同步点明这条边界（顶栏/日志不摆，标签页图标不在此列）。

## 理由

- "界面内不摆图标"的初衷是**界面保持纯文字、不引入装饰**，与"浏览器标签页有图标"并不冲突：
  标签页图标由浏览器外壳渲染，不进面板布局。
- Emby 默认头像复用同一张品牌图，避免品牌在多处各画一套。
- 两处都用**位图 PNG**，与前端零构建（[0014](0014-frontend-no-build.md)）一致：不需要图标字体、
  不需要打包 SVG 雪碧图，静态服务按 `.png` 直接给字节。

## 备选方案

- **把图标也摆进顶栏 / 日志**：与既有"界面内纯文字"决策冲突，否决。
- **用内联 SVG 重画图形**：图形本身是位图资产，重画等于维护两套且会走形；直接用导出的 PNG。
- **只做标签页图标、不动默认头像**：Emby 默认头像会继续停在旧占位图上，品牌不一致。
- **把源图（设计稿）也入库**：仓库只需要能直接服务的成品；源图入库徒增体积与两份真相。

## 后果

- **改品牌图形时改这三处**：设计源图、[public/logo.png](../../public/logo.png)、
  [default-avatar.png](../../server/modules/emby/assets/default-avatar.png)（由同一张源图导出）。
  仓库里只放**导出的 PNG**，源图不入库。
- **Emby 默认头像换图会影响客户端缓存**：`tag` 是文件内容 md5，图变了 `tag` 就变，
  客户端会重新拉一次头像。尺寸仍是 606×606，[emby-compat.md](../emby-compat.md) 那条口径继续成立。
- **图形资产是位图不是矢量**：放大到超过导出尺寸会糊。当前导出尺寸（512 / 606）已覆盖
  标签页图标与头像的实际显示尺寸。
