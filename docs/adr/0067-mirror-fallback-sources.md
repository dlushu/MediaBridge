# ADR-0067 取源候选：内置公共 gh 代理，串行降级到官方直连

- 状态：已采纳
- 相关：[core/mirrors.js](../../server/core/mirrors.js)（候选表与超时的**共用实现**） ·
  [update.js](../../server/modules/panel/update.js)（面板自身更新） ·
  [library.js](../../server/modules/plugin/library.js)（插件库取清单与包） ·
  容器引导脚本 `docker/entrypoint.js`（由维护者维护，与容器定义一起放在版本库之外） ·
  [0019](0019-self-update-from-release.md)（自身更新的总体口径，本条细化其「下载地址可配置」一节的默认值）

## 背景

项目从 GitHub 取两类东西，国内网络下都不稳：

- **应用代码**（取自 GitHub Release，见 [0019](0019-self-update-from-release.md)），要打三跳：
  1. 查最新版本：`https://api.github.com/repos/<repo>/releases/latest`；
  2. 下包体：`https://github.com/<repo>/releases/download/v<ver>/media-bridge-panel-<ver>.tar.gz`
     （会 302 到 `objects.githubusercontent.com`）；
  3. 下校验：同 2 的地址加 `.sha256`。
- **插件库**（清单 `index.json` 与各插件包，见 [library.js](../../server/modules/plugin/library.js)）：
  走 `raw.githubusercontent.com`，国内同样常有连接/超时问题。

此前唯一的逃生口是手工填 `APP_SOURCE_URL` / `APP_CHECKSUM_URL`（应用代码）或
`PLUGIN_INDEX_URL` / `PLUGIN_SOURCE_URL`（插件库）—— 都是单值、且用户得自己先找到一个可用代理
再抄进环境变量，部署门槛高；应用代码查版本这一跳更是没有任何退路。

## 决定

**引入候选地址表，按顺序串行降级**：内置若干公共 gh 代理前缀，官方直连恒为最后兜底。
候选表与超时抽到共用实现 [core/mirrors.js](../../server/core/mirrors.js)（`core/` 是允许被模块依赖的
基础设施，见 [0001](0001-module-boundaries.md)），**面板自身更新与插件库共用这一份**，避免两份漂移。

### 候选构成

- 内置默认候选：`https://gh-proxy.com`、`https://ghfast.top`（均为「前缀型」gh 代理，
  地址形如 `<前缀>/<官方地址>`）。这两个是实测在候选集中**唯一能同时覆盖三跳**的（见下方「实测」）。
- `APP_MIRRORS`：逗号分隔、**有序**的前缀列表，覆盖内置默认；置 `off` / `none` / `-` 关闭镜像、
  只走官方直连。只接受 `http(s)` 前缀，空项与非法项丢弃。
- **显式设了 `APP_SOURCE_URL`（或插件库的 `PLUGIN_INDEX_URL` / `PLUGIN_SOURCE_URL`）就是唯一地址**，
  不再套镜像前缀（用户自己指哪打哪，不再作额外推断）。
- 候选按用途各自展开：应用代码查版本用 `versionCandidates()`、取包用 `sourceCandidates()`；
  插件库取清单用 `indexCandidates()`、取包用 `sourceCandidates()`。它们都以官方直连收尾。

### 降级与超时

- 查版本 / 取清单：按候选逐条请求，第一个成功的胜出；全失败才抛错，错误里列出每个地址各自的原因。
- 取包：按候选逐条试「下载包体 → 取校验值 → 比对」，第一个**校验通过**的胜出（应用代码用 sha256，
  插件库用清单里申报的 md5）。
- **单次请求 20 秒超时**（`AbortSignal.timeout`）。不设超时的话，一个挂死的候选会把整次取源拖黄 ——
  降级的前提是「失败要快」，超时是降级能成立的必要条件。
- **不做并发探测**：并发会放大对上游的请求量（一次取源变成 N 个同时请求），与
  [AGENTS.md](../../AGENTS.md) 「请求扇出放大不擅自做主」的口径冲突；串行降级在最坏情况下多等几秒，
  但请求量仍是 1 倍。

## 理由

| 做法 | 优点 | 缺点 |
|---|---|---|
| **内置候选 + 串行降级**（本决定） | 国内默认可用，无需用户先找代理 | 默认信任第三方代理（见「安全口径」） |
| 只保留手工 `APP_SOURCE_URL` | 不引入默认信任 | 部署门槛高；第 1 跳仍无退路 |
| 内置候选但并发探测 | 快 | 放大上游请求量，与既有口径冲突 |

## 安全口径（重要）

**走第三方代理时，校验退化为「只防传输损坏」。**

原因：候选表默认让「包体」与「配套的校验值」走**同一个代理前缀**（应用代码的 `sum = ${src}.sha256`；
插件库的 md5 申报在清单里，清单本身也经代理）。两者都经代理之手。代理是 TLS 中间人，明文在它这一侧，
可以同时替换包体与其校验值而不被察觉 —— 客户端拿到的校验始终"对得上"，校验通过，但装下的可能是被替换过的包。

本决定**接受这一降级**，并在 README 与本文写清，理由：

- 用户本就在用不可信的公共网络通道，代理只是把"信任面"从 GitHub 换成了代理；
- 要真实校验，就把 `APP_SOURCE_URL`（插件库同理用 `PLUGIN_INDEX_URL` / `PLUGIN_SOURCE_URL`）显式指向
  **自己信任**的镜像（此时不套代理前缀，包体与校验同源可控）；
- 不默认关闭候选，是因为"国内开箱即用"是本条要解决的问题，而"代理篡改"是更小的风险面。

> 这是一个**有意接受**的取舍，不是遗漏。若将来要恢复强校验，方向是引入**独立于包体来源**的校验
> 通道（例如把预期 sha256 写进面板自己的发布元数据），而不是回到"只认官方直连"。

## 备选方案

- **只信官方直连、失败即报错**：最安全，但正是当前国内部署的痛点，等于不做。
- **把候选列表做成可被远程下发的配置**：多一层信任面（下发通道本身也需可信），且引入"配置拉不到
  就用不了"的新故障模式；候选是低频变更项，内置 + 环境变量覆盖已够。
- **并发探测取最快**：快，但放大上游请求量，且对"哪个候选真的能验签通过"没有帮助（快 ≠ 完整）。

## 后果

- **应用侧共用一份，引导脚本独立一份**：应用侧 `server/modules/panel/update.js`（面板自身更新）与
  `server/modules/plugin/library.js`（插件库）都 `require` [core/mirrors.js](../../server/core/mirrors.js)，
  改默认候选只动这一处；但容器引导脚本 `docker/entrypoint.js` 在**首装时应用代码还不存在**，不能
  import 应用代码，只能**另存一份**同样的表 —— 所以改默认候选时，`core/mirrors.js` 与
  `docker/entrypoint.js` **两处都要同步**（与 [0019](0019-self-update-from-release.md) 的「两者一同演进」一致）。
  引导脚本在 `docker/` 下（不入库），**改它必须重推镜像**。
- **默认把公共代理摆在官方直连之前**：官方可达时也会先经代理走一遍（多一跳）。这是"国内默认可用"
  的代价；在意这一跳或在意信任面的用户，用 `APP_MIRRORS=off` 只走官方。
- `current.json` 的 `source` 字段会记录**实际取胜的那个地址**（可能是代理地址），便于事后核对
  「这一版是从哪装来的」；插件库 `download()` 同样把实取胜出的地址回传（面板 `/api/plugins/library`
  的 `sourceUrl` 记的是**首选**地址，实装可能经镜像候选）。
- 候选是**可失效**的：公共代理会下线或改行为，故默认只是"起手可用"，不承诺长期有效；
  失效时换 `APP_MIRRORS` 即可，无需改代码。

### 实测（2026-10，12 家候选）

- `gh-proxy.com` 是唯一**三跳全通**者（api + Release 说明正文 + 包体 + 校验）。
- `ghfast.top` 资产（包体 + 校验）可下，api 403，但其 HTML 版页面能抓到版本号 —— 因候选必要性，
  它仍在默认列表中（取包这一跳可用；查版本这一跳会失败并落到下一个候选）。
- 两家取到的包体 sha256 与官方一致；其余 9 家候选因连接/SSL 失败、Cloudflare 挑战，或
  「HTTP 200 但返回错误页/落地页」被淘汰 —— 后者说明**只判状态码会误收**，必须靠 sha256 兜住。
